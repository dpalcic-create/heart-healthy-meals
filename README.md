# Heart-Healthy Meals

A standalone, offline-friendly meal planner for simple, tasty plates that stay inside a gluten-free, dairy-free, no-added-sugar, high-protein pattern.

**Live app:** https://dpalcic-create.github.io/heart-healthy-meals/

Open `index.html` in a browser, or use the link above. Favorites, the weekly plan, shopping checks, and pantry ticks are saved in that browser.

This is not medical advice. Nutrition numbers are estimates. Follow your doctor's guidance.
